# DSH Go b9 验收测试清单（给执行 AI）

对象：`DSH-Go-1.11-b9-hotfix-arm64.apk`（b9 最终包 + 运行时装包卡死的修复）
若无热修包，用 `DSH-Go-1.10-b9-final-arm64.apk`，但先做 A1 的前置（它会卡安装）。
环境：`设置 → 帮助与关于 → 能力控制` 是功能入口；知识库与导出物在 `/sdcard/Download/DSH-Go/`。

约定：`→` 界面路径；【】要观察的现象；⚠ 失败算严重。每条填「通过/失败/跳过 + 证据」。

## A 安装与启动
- A1 覆盖安装热修包 → 能进界面；`设置→引擎` 运行中；原会话/知识库都在。（若卡在「安装未完成」，先重启手机再装；仍卡 = 该 bug 未修）
- A2 `能力控制` 能看到 **知识库 / 看护 / 授权记录** 三个入口。
- A3 ⚠ 冷启动：划掉最近任务再开 → 10 秒内进界面，不白屏不闪退。

## B 知识库（`能力控制 → 知识库`）
- B1 空库：显示「还没有文档」「0 个 · 0 块」，顶部给目录路径。
- B2 自动收录：放一个 `测试.md`（200 字）进知识库目录，回页面 → 列表出现，块数/大小对。
- B3 导入复制：点「导入文件」选一个 txt → 被**复制**进知识库目录（原件还在）。
- B4 不支持格式：选 pdf → 提示跳过（只收 txt/md/html/csv/json/docx）。
- B5 预览：点文档 → 显示前 1～3 块正文。
- B6 ⚠ 删除确认：垃圾桶 → 先问；取消文件还在；确认后列表少一条 + 文件没了。
- B7 重建索引：点它 → 显示「重建完成：N 文档 M 块」，时间更新。
- B8 检索引用：问一个只有该文档才有的词 → 命中并给路径；问不存在的 → 答「没有」，不编。

## C 爬虫（web_crawl）
- C1 直取：让它「把 https://example.com 存进知识库」→ 抓 1 页；`知识库/网页/example.com/` 出现 md，头有 `url:` 与 `fetched:`。
- C2 ⚠ 增量：同一页再抓 → unchanged，文件修改时间不变。
- C3 同域限量：`depth=1 limit=5` → 最多 5 页、只同域。
- C4 渲染：`render=true` 抓 JS 页面 → 内置浏览器打开该页，正文非空。
- C5 robots：抓被 robots 禁止的路径 → 不抓，结果写明「被 robots 禁止 N 页」。
- C6 断网：飞行模式抓页面 → 失败提示、会话不崩、不超 1 分钟。

## D 导入导出（`设置 → 隐私与分享`）
- D1 分类勾选：导出对话框有 9 类，前 5 类默认勾；每类有大小与文件数；按钮显示合计。
- D2 ⚠ 只勾会话：解压 zip → 只有 `manifest.json` 与 `root/.dsh/sessions/`。
- D3 ⚠ 密码不进包：勾上会话/设置/云盘/代理 → 解压看 `config/prefs.json`：无密码、无订阅地址/token、无 API Key。
- D4 知识库：勾「知识库」→ zip 里有 `host/kb/…`，**没有** `.index`。
- D5 ⚠ 导入预览：选包 → 先出预览（时间/分类/新增覆盖数）；到这一步点取消，不写任何文件。
- D6 冲突三选：分别「跳过」「保留两份」各导一次 → 跳过时本机不变；保留两份时出现 `名字 (1).md`。
- D7 ⚠ 自动备份：导入后下载目录多出 `dsh-go-before-import-<时间>.zip`，提示里带文件名。

## E 授权永久化
- E1 读网页：审批卡有 **「总是允许（永久）」**。
- E2 ⚠ 跑 bash / 写文件：审批卡**没有**该项。
- E3 永久生效：点「总是允许」→ 再读另一个网页不再弹卡。
- E4 撤销：`授权记录` 找到那条 → 撤销 → 再读重新弹卡。
- E5 全部清除：清空后列表为空，之后都重新问。
- E6 ⚠ 能力联动：上传授权后关「浏览器」开关 → 授权记录里标「已失效（能力已关）」；打开后恢复。
- E7 上传三选一：取消 / 总是允许（这个站点）/ 允许本次；选总是允许后同站点不再弹。

## F 看护（`能力控制 → 看护`）
- F1 添加：网址 + 名字 + 间隔 5 分钟 → 立刻有一条，副标题「每 5 分钟 · 上次 刚刚」，下方有正文片段。
- F2 立即检查不变：点该条 → 「和上次一样」。
- F3 ⚠ 变化通知：盯一个会变的页面 → 变化次数 +1，状态栏出现「看护：<名字> 有变化」。
- F4 暂停/恢复：开关关掉 → 显示已暂停、不再到点检查；开回来恢复。
- F5 删除：垃圾桶 → 确认 → 列表少一条。
- F6 边界：打不开的网址 → 列表显示「打不开这个页面」，App 不卡。

## F2 一句话流程
- F7 存技能：「把这套操作存成技能，叫 weather-brief」→ `skill_save` 返回 `skills/weather-brief/SKILL.md`，文件有 name/description/编号步骤。
- F8 列技能：「列出我有哪些技能」→ 列表里有它。
- F9 删技能：「把 weather-brief 删掉」→ 目录没了，再列不出现。
- F10 非法名字：叫「测试 技能」→ 返回 bad_name，不写文件。

## G 剪贴板动作
- G1 触发：别处复制一个网址，回聊天页 → 输入框上方出现小条（粘贴 / 存进知识库 / ×）。
- G2 粘贴：点粘贴 → 进输入框，接在草稿后，光标在末尾，小条消失。
- G3 存进知识库：复制长文字 → 点它 → 提示「已存进知识库：笔记/」，`知识库/笔记/` 多一个 md。
- G4 不用：点 × → 消失，同一段不再出现。
- G5 短内容：复制「好的」→ **不出现**小条。

## H 回归
- H1 浏览器多标签开/切/关 · H2 下载到下载目录 · H3 截图能打开 · H4 上传（三选一）· H5 代理订阅启动与停止 · H6 通知中枢能读、规则能加 · H7 常驻/电池白名单/开机自启（真重启验）· H8 手机操控读屏与点按确认 · H9 云盘列目录/上传/下载 · H10 关「浏览器」开关后让它开网页 → 直接 denied，且「最近的拒绝」有记录

## I 异常
- I1 知识库目录被删 → 页面 0 篇，重放文件能收录 · I2 20MB md → 能收录、页面不卡死 · I3 断网重建索引 → 正常完成 · I4 坏 zip → 提示不是存档，不写文件 · I5 别人的 zip → 同上 · I6 检查看护时杀进程 → 再看列表和上次内容还在 · I7 200 篇文档 → 列表显示前 300 并提示总数，3 秒内出内容
