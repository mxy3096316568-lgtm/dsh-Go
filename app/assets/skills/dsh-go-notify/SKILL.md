# 通知中枢

App 用一个通知读取服务把最近收到的通知存下来（最多 300 条），下面这些工具能读它。

| 工具 | 用途 |
|---|---|
| `notify_list` | 最近的通知（新的在前），可按应用过滤 |
| `notify_search` | 在通知里按关键词搜 |
| `notify_digest` | 按应用汇总：多少条、最新一条，附最近列表 |

每条通知的字段：`app`（应用名）、`package`（包名）、`title`、`text`、`time`、`timeText`、`ongoing`。
工具还会给一份 `lines`（已经拼好的「[应用] 时间 标题：正文」），直接引用它更省事。

## 怎么用

1. 用户说「帮我看看有什么消息」→ 先 `notify_digest`，看哪些应用在响。
2. 要细节再 `notify_list(app="微信")`，或者 `notify_search(query="快递")`。
3. 汇总时按应用分段，时间用 `timeText`，别自己编时间。

## 分寸

- 通知里有验证码、转账、私密对话：只在用户问的那件事里用，别主动复述给其他人，也不要写进长期记忆。
- 没有权限时工具返回 `denied`：提示用户去 设置 → 能力控制 → 通知 → 「通知读取权限」点一下打开，别反复重试。
- 通知只会被读取，不会被改动；不要承诺「帮你回复这条消息」，除非用户明确要你去做（那要走手机操控或对应应用）。
- 一直只有几十条旧数据多半是没授权或授权后没新通知，说清楚就行。
