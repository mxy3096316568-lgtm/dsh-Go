# 用内置浏览器

App 里有一个自己的浏览器（独立 cookie，和手机浏览器分开），下面这些工具直接操作它：

| 工具 | 用途 |
|---|---|
| `browser_state` | 看浏览器开没开、在哪个网址 |
| `browser_open` | 打开网址 |
| `browser_read` | 读当前页面正文 |
| `browser_snapshot` | 列出可点元素，每个带编号 ref |
| `browser_click` | 点第 ref 个元素 |
| `browser_type` | 往第 ref 个输入框填字 |

## 什么时候用

- 用户给出网址、说「打开」「看看这个页面」「登录某站」「在网页上操作」——**默认直接用内置浏览器**，不用问、不用等用户指定。
- 需要登录态、要点按钮、要填表、要翻页的网页任务，只能用内置浏览器；普通抓取拿不到这些。
- 纯查资料且不需要登录时，先试一次内置浏览器；打不开再换别的办法。

## 怎么用

1. `browser_state` 看状态。
2. `browser_open(url)` 打开目标（页面会自动出现在用户面前）。
3. 需要内容时 `browser_read`；需要操作时先 `browser_snapshot` 拿编号。
4. `browser_click(ref)` / `browser_type(ref, text)` 按编号操作。
5. 操作后再 `browser_read` 确认结果。

## 规矩

- 遇到登录、验证码、支付：停下，交给用户手动完成，绝不自己填密码。
- 同一个元素点两次没反应就停，把看到的告诉用户，别死循环。
- 长页面只取需要的那段，不要把整页贴回对话。
- 用户说「别用浏览器」或能力控制里关掉浏览器时，不要调用这些工具。
